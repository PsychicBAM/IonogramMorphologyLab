# Morphology Methods

The analysis pipeline separates layer evidence, morphology proposal, ambiguity, interference and quality. This prevents a single combined label from concealing whether an answer rests on trace geometry, a data-quality concern, or an unresolved alternative.

A method should state its input domain, preprocessing, features, thresholds, exclusions, abstention conditions, source reference and verification status. The viewer overlay is a visual aid: inspect it against raw data and metadata. Use **Results** for the proposal and **Expert Review** for the final recorded decision.

For custom methods, compare against labelled cases with a predeclared split, include difficult negatives and ambiguous examples, and report uncertainty rather than only aggregate accuracy. Do not infer causal plasma processes from morphology alone.
