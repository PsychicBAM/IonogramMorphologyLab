# MATLAB Studio — руководство пользователя (1.1.1)

## Назначение

MATLAB Studio — **опциональное** рабочее пространство для хранения, версионирования, запуска и проверки скриптов MATLAB и GNU Octave. Приложение не зависит от проприетарной среды: поддерживаются воспроизводимые исследовательские процедуры, но не автономная научная сертификация.

Основные функции IML (импорт, viewer, batch, экспертная проверка, отчёты) работают при отключённом выполнении (`backend none`).

## Начало работы

1. Откройте **MATLAB Studio** в левой навигации.
2. Выберите backend в **Settings → MATLAB**.
3. Идентификаторы: `matlab_engine`, `octave`, `external_matlab`, `none`.
4. Состояние `none` на машине без MATLAB допустимо: библиотека, манифесты, редактирование и упаковка доступны; выполнение явно отключено.

## Библиотека скриптов

Импортируйте или создайте скрипт в библиотеке проекта или общей библиотеке. Каждое сохранение создаёт версию с хешем, временем, комментарием и версией приложения **1.1.1**.

- Используйте понятные имена и научный статус в манифесте.
- Импортированный код **не** верифицируется только потому, что запустился.
- Сторонние `.m` файлы — как любой непроверенный код.

## Запуск

1. Выберите скрипт и проверьте манифест (входы, выходы, статус).
2. Контекст: текущий кадр, выбранные кадры или последовательность.
3. Укажите параметры и тайм-аут.
4. Запустите задачу; проверьте статус, журнал, файлы и зарегистрированные результаты.

Задача выполняется в отдельном каталоге. Входы копируются в bridge-файлы; исходные MAT хешируются до и после запуска. Статусы: `ok`, `error`, `timeout`, `cancelled`, `no_backend`. **`no_backend` не означает успешный анализ.**

## Обмен данными

| Артеfact | Роль |
|----------|------|
| `iml_bridge_inputs.mat` | Матричные данные для скрипта |
| `iml_metadata.json` | Контекст и параметры |
| помощники `iml_*` | Регистрация матриц, рисунков, таблиц в результате |

Не записывайте данные обратно в импортированный MAT — исходник по умолчанию только для чтения.

## Научные ограничения

Результат MATLAB — **кандидатный**. Регистрируйте признаки, предупреждения и provenance с версией алгоритма и параметрами. Успешный запуск, график или нулевой код выхода **не** подтверждают валидированную морфологию или физический механизм. До решения эксперта проверьте неоднозначность O/X, качество, профиль и abstention.

## UX-режимы

| Режим | MATLAB Studio |
|-------|---------------|
| Guided | Отложен — переключитесь на Research/Expert на Home |
| Research | Доступен с предупреждениями |
| Expert | Полный редактор, журнал, манифесты |

## Устранение проблем

| Проблема | Действие |
|----------|----------|
| Нет выполнения | Путь backend; работа без запуска |
| Тайм-аут | Уменьшите объём; повышайте лимит после проверки скрипта |
| Невалидный манифест | Исправьте обязательные поля |
| Нет результатов | Сохранение через `iml_*` |

Сохраняйте журналы и provenance для отчёта об ошибке — без чувствительных путей.
