# MATLAB Studio — руководство пользователя (1.1.1)

## Назначение

MATLAB Studio — **опциональное** рабочее пространство для хранения, версионирования, запуска и проверки скриптов MATLAB и GNU Octave. Приложение не зависит от проприетарной среды: поддерживаются воспроизводимые исследовательские процедуры, но не автономная научная сертификация.

Основные функции IML (импорт, просмотр ионограмм, пакетный анализ, экспертная проверка, отчёты) работают при отключённом выполнении (способ запуска `none`).

## Начало работы

1. Откройте **MATLAB Studio** в левой навигации.
2. Выберите исполнительную среду в **Настройки → MATLAB**.
3. Идентификаторы способа запуска: `matlab_engine`, `octave`, `external_matlab`, `none`.
4. Состояние `none` на машине без MATLAB допустимо: библиотека, манифесты, редактирование и упаковка доступны; выполнение явно отключено.

## Библиотека скриптов

Импортируйте или создайте скрипт в библиотеке проекта или общей библиотеке. Каждое сохранение создаёт версию с хешем, временем, комментарием и версией приложения **1.1.1**.

- Используйте понятные имена и научный статус в манифесте.
- Импортированный код **не** верифицируется только потому, что запустился.
- Сторонние `.m` файлы — как любой непроверенный код.

## «Проверить код без запуска» и «Запустить в MATLAB»

| Элемент | Действие |
|---------|----------|
| **Проверить код без запуска** | Проверяет структуру редактора и базовые требования IML. MATLAB **не** запускается; научный результат не вычисляется. Итог — во встроенной карточке и в «Техническом журнале». |
| **Запустить в MATLAB** | Выполняет выбранный метод через настроенную исполнительную среду (`matlab_engine`, `octave` или `external_matlab`). Не используйте общую метку «Запуск» при нескольких способах запуска. |

## Ожидаемый результат метода

Перед запуском панель **«Ожидаемый результат метода»** (из метаданных/манифестов) указывает, должен ли метод дать: скаляры, признаки, научные кандидаты, таблицы, матрицы, диагностические изображения, рисунки, файлы или только предупреждение. **Не каждый метод создаёт изображение.** Параметрические методы прямо это указывают.

## Запуск

1. Выберите скрипт и прочитайте **«Ожидаемый результат метода»**.
2. При необходимости нажмите **«Проверить код без запуска»** (без выполнения MATLAB).
3. Контекст: текущий кадр, выбранный диапазон, один файл или папка.
4. Нажмите **«Запустить в MATLAB»**; просмотрите сводку и вкладки (Значения, Признаки, Кандидаты, Рисунки, Таблицы, Матрицы, Файлы, Предупреждения, Журнал, Происхождение).

Задача выполняется в отдельном каталоге. Входы копируются в bridge-файлы; исходные MAT хешируются до и после запуска. Нулевой код выхода процесса **недостаточен** для научного успеха. IML различает: зарегистрированный выход; только файлы; нет зарегистрированного выхода; ошибка; отмена; таймаут. Также: `no_backend`. **`no_backend` не означает успешный анализ.**

## Обмен данными

| Артефакт | Роль |
|----------|------|
| `iml_bridge_inputs.mat` | Матричные данные для скрипта |
| `iml_metadata.json` | Контекст и параметры |
| помощники `iml_*` | Регистрация матриц, рисунков, таблиц в результате |

Не записывайте данные обратно в импортированный MAT — исходник по умолчанию только для чтения.

## Научные ограничения

Результат MATLAB — **кандидатный**. Регистрируйте признаки, предупреждения и происхождение и параметры выполнения (версия алгоритма и параметры). Успешный запуск, график или нулевой код выхода **не** подтверждают валидированную морфологию или физический механизм. До решения эксперта проверьте неоднозначность O/X, качество, профиль и воздержание от классификации.

## Режимы интерфейса

| Режим | MATLAB Studio |
|-------|---------------|
| Обучение | Отложен — переключитесь на Исследование/Эксперт на главной |
| Исследование | Доступен с предупреждениями |
| Эксперт | Полный редактор, журнал, манифесты |

## Устранение проблем

| Проблема | Действие |
|----------|----------|
| Нет выполнения | Путь исполнительной среды; работа без запуска |
| Тайм-аут | Уменьшите объём; повышайте лимит после проверки скрипта |
| Невалидный манифест | Исправьте обязательные поля |
| Нет результатов | Сохранение через `iml_*` |

Сохраняйте журналы и происхождение выполнения для отчёта об ошибке — без чувствительных путей.
