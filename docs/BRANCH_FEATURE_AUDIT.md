# Branch Feature Audit (Feature Pipeline V2)

## Measurements / candidate interpretations

- Component count, branch count  
- Separation, parallelism  
- Merge/split locations  
- Relative amplitude  
- Overlapping-layer / multiple-reflection / O/X-ambiguity **possibility** flags  

## Hard limits

- Branch count alone does **not** prove mixed Spread-F.  
- O/X flags are ambiguity candidates — **not** physical mode declarations from Amp_all.
