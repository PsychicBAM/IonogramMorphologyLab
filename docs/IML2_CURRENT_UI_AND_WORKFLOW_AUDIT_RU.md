# IML-2 Аудит текущего UI и рабочего процесса (RU)

**Приложение:** Лаборатория морфологии ионограмм 0.1.0 (IML-1 MVP)  
**Дата аудита:** 2026-08-01  
**Область:** Удобство интерфейса — слепые данные Article 3 не просматривались.

## Текстовые описания экранов

### Главная
Краткое приветствие и научная оговорка. Нет пошагового «что делать дальше».

### Новый проект
Одно поле имени. Статус показывает полный путь на диске (для разработчика).

### Импорт данных
Кнопки файла/папки работают. Результат — строки вида  
`status=valid adapter=scipy_mat_v5 vars=1`.  
Импортированные пути **не связаны** с просмотрщиком.

### Профиль инструмента
Загрузка профиля KFU выводит **сырой YAML/JSON**. Мастер печатает имена шагов.

### Аудит данных
Выводит **сырой JSON** аудита.

### Просмотр ионограмм (критический разрыв)
Кнопка «Render synthetic demo frame» всегда рисует синтетику.  
Нет связи с реальным MAT, индексом кадра, временем, кэшем, контактным листом, воспроизведением.

### Пакетный анализ
Только `frame_step`. При шаге 121 получается 12 кадров без объяснения.  
Журнал — сырой JSON.

### Результаты / Атлас / Научная основа / Помощь / Настройки
Сырой JSON/CSV; помощь — одно предложение; настройки — почти только язык; возможна рассинхронизация RU/EN.

## Корневые причины

См. таблицу в английской версии аудита: Viewer не привязан к импорту; нет превью числа кадров; нет FrameStore/кэша сессии в UI; неполный i18n.

## Сохраняемые ограничения

Пороги правил, прослеживаемость, blocklist, воздержание и формулировки «кандидатная морфология» в IML-2 не ослабляются.
