# Руководство пользователя (RU) — Ionogram Morphology Lab 1.1.1

## Безопасный старт

1. Запустите `IonogramMorphologyLab.exe` (портативная сборка) или точку входа для разработки.
2. Выберите язык при первом запуске (позже: **Настройки → Общие → Язык интерфейса**).
3. Создайте проект в доступной для записи папке вне каталога установки. Папки проектов и кэша можно задать в **Настройки → Хранилище**.
4. Начните с учебных файлов в [`synthetic_data/`](../synthetic_data/) до работы с исследовательскими данными.

## Страница «Проекты»

На странице **Проекты** три раздела:

1. **Текущий проект** — имя, путь, дата создания, последнее открытие, активный исходный файл, активный запуск, несохранённые изменения.
2. **Открыть проект** — **Открыть проект**, **Выбрать папку проекта**, **Открыть недавний проект**, список недавних с доступностью, **Открыть** и **Удалить из списка недавних**.
3. **Создать проект** — новый проект анализа в доступной родительской папке.

Перед сменой проекта приложение спрашивает о несохранённых правках, останавливает или разрешает активные задачи и очищает устаревшее состояние интерфейса, чтобы не смешивать результаты двух проектов.

## Рекомендуемый порядок работы

1. **Импорт данных** — файл или папка MAT; исходные MAT не перезаписываются.
2. **Аудит данных** — переменные, размеры, метки времени, предупреждения.
3. **Профиль инструмента** — выберите или создайте профиль; предварительные метаданные помечайте как provisional.
4. **Просмотр ионограмм** — кадр X из N, готовность кэша; кэш только производный.
5. **Пакетный анализ** — что анализировать (текущий кадр, диапазон, время, каждые N минут, весь файл, список), сводка подтверждения, затем запуск. Кнопка «Старт» неактивна, пока выбор некорректен.
6. **Результаты** — переведённая морфология и панель доказательств. Канонические токены — только в **Технических сведениях**.
7. **Экспертная проверка** — Accept / Change / Indeterminate / N/A с обоснованием.
8. **Отчёты → Экспорт** — проверьте происхождение данных перед передачей.

## Пример пакетного анализа

Анализ кадров с **05:00 до 07:00 каждые 10 минут**:

1. Откройте **Пакетный анализ**.
2. Выберите **Каждые N минут** (или диапазон времени с шагом 10).
3. Задайте 05:00–07:00 и интервал 10 минут.
4. Предустановка **Стандартный анализ**.
5. Проверьте сводку и запустите анализ.
6. Откройте **Результаты**.

## Хранилище

В **Настройки → Хранилище** доступны пути для проектов, рабочей области, кэша, отчётов, моделей, MATLAB и временных файлов. Действия:

- Обзор / Открыть папку
- Перенести кэш (с откатом при ошибке)
- Очистить кэш (исходные MAT не удаляются)
- Восстановить пути по умолчанию

## Ярлык на рабочем столе

**Настройки → Создать ярлык на рабочем столе** (с подтверждением). Права администратора не требуются.

## Режимы навигации

- **Обучение** — Начало, Данные, Анализ, Отчёты, Настройки, Справка
- **Исследование** — обычный научный поток; группа «Методы» свёрнута
- **Эксперт** — все разделы

Режим меняет только видимость интерфейса, не научные результаты.

## Важные границы

- Результат — **кандидат морфологии**, а не доказательство физического механизма.
- Исходные данные только для чтения; кэш и отчёты — производные.
- Канонический токен без рассеяния: `clean` («Явное рассеяние не обнаружено»).
