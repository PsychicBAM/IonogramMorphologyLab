# Testing

The baseline command is `python -m pytest`. CI also runs repository hygiene, README-link and version-consistency validators; it does not require MATLAB or a display. Add unit tests beside behavioral changes, integration tests for import/provenance flows, and regression tests for security-sensitive parsing.

Use synthetic fixtures only. A passing technical test does not establish a morphology method?s scientific validity; rule and model changes require documented empirical evaluation as well.
