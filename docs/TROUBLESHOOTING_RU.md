# Устранение неполадок — 1.1.1

Типовые проблемы Ionogram Morphology Lab и порядок действий. Ниже приведены английские подписи элементов интерфейса; при языке **Русский** соответствующие пункты меню отображаются по-русски.

## Сбой импорта

Убедитесь, что файл — поддерживаемый **MAT v5/v7** (SciPy) или **v7.3/HDF5** (h5py), доступен вашей учётной записи и содержит ожидаемую переменную-массив.

1. Откройте **Import Data → Data Audit**.
2. Сохраните **точный текст предупреждения** в журнале исследования.
3. Не перезаписывайте ограниченный исходный файл на месте; используйте рабочую копию по политике проекта.
4. Сверьте имя переменной, форму и тип данных с документацией прибора.

Неизвестная в аудите структура означает **непроверенную** совместимость до вашей валидации.

## Нет кадров или неверная ориентация

1. В **Instrument Profile** проверьте частотные/высотные бины, шаг МГц и сопоставление переменных.
2. В **Viewer** сравните кадр с выбранным преобразованием и направлением навигации.
3. Помечайте provisional-метаданные до экспертного подтверждения масштаба.

Исправление отображения **не** доказывает научную корректность метаданных.

## Анализ заблокирован или кэш медленный

1. Уменьшите объём импорта для первых тестов.
2. Обеспечьте место на диске под кэш Zarr в workspace проекта.
3. **Build cache** — только для стабильных производных данных.
4. При пересборке удаляйте **только производный кэш**, не исходный MAT.

Home показывает заблокированные шаги, если не выполнены профиль или кэш. В обращении в поддержку не включайте чувствительные пути.

## Backend MATLAB недоступен

Основные сценарии **не** требуют MATLAB.

1. **MATLAB Studio** и **Settings → MATLAB** — статус backend.
2. При необходимости запуска проверьте лицензию MATLAB или путь Octave.
3. Используйте встроенные методы или Python-конвейер при `none` / `no_backend`.

`no_backend` после попытки запуска означает отключённое выполнение, а **не** успешный анализ.

## Правило не выполняется

1. **Rule Builder** — ID, целевая ось, признаки, единицы, применимость, статус.
2. **Preview generated code** — ветки воздержания и исключений.
3. **Rule Testing Lab** — размеченная dev-выборка.

Синтаксически корректное правило может быть научно неприменимо к вашему профилю или эпохе.

## Неполный отчёт или экспертная проверка

1. **Expert Review** и **Ionogram Parameters** — сохраните решения с обоснованием.
2. Повторный **Export** из **Reports** с полями provenance.
3. Проверьте версии rule pack и ID профиля в метаданных.

HTML/Markdown могут содержать локальные пути — проверьте перед публикацией.

## Производительность и память

| Симптом | Мера |
|---------|------|
| Зависание при batch | Меньше кадров; меньше workers в Settings |
| Заполнение диска | Архив проектов; удаление только derived cache |
| Медленное открытие MAT v7.3 | Нормально для крупного HDF5; один раз Build cache |
