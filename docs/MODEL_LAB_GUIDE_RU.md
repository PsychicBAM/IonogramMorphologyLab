# Руководство Model Lab

## Область применения
Model Lab — необязательное рабочее пространство разработки для обучения и сравнения классификаторов по CSV с размеченными признаками. Это не диагностический продукт; модели предназначены только для разработки/исследований, пока не пройдут внешнюю валидацию для заявленных популяции, прибора, меток и назначения.

## Процедура
Подготовьте CSV с числовыми признаками, колонкой `label` и желательно группировкой `date` либо последовательностью. Импортируйте файл в Model Lab, проверьте числа классов и признаки, выберите модель, обучите её и изучите созданную model card. Поддерживаются логистическая регрессия, линейный/RBF SVM, random forest, gradient boosting, k-nearest neighbors и конфигурация calibrated ensemble.

## Контроль утечки
Разбиение по умолчанию — `by_date`: соседние кадры одной даты/последовательности нельзя бездумно разделять между train и test. Метрика на hold-out говорит только об этом разбиении, а не об универсальной точности. В model card фиксируются источник, seed, классы, политика split и предобработка.

## Model card и неопределённость
Новые model card помечаются `development`, содержат ограничения и указывают, что слепые метки Article 3 не использовались. Статус калибровки может быть `uncalibrated`. Оценка может отсутствовать (`confidence_score: null`), то есть калиброванной вероятности нет. Ниже порога модель возвращает `abstain`; это допустимый результат, требующий проверки.

## Ответственное применение
Нельзя использовать результат модели как окончательную морфологию, причинный механизм либо клиническое/операционное решение. Сопоставляйте его с качеством данных, интерпретируемыми признаками, правилами, референсным контекстом и экспертом. Перед изменением статуса заявления нужна независимая документированная внешняя валидация.

## Проблемы
Нужны не менее двух жизнеспособных классов и достаточно групп для split. Удалите нечисловые значения признаков или задайте колонки явно. Если модель не выдаёт вероятностей, сохраняйте null, не подставляйте оценку. Архивируйте CSV, card и детали окружения вместе с результатами.
