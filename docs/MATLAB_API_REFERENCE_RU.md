# Справочник MATLAB Bridge API

Все помощники работают в изолированном рабочем каталоге MATLAB Studio. Это поддерживаемый интерфейс между скриптом и «Лабораторией морфологии ионограмм» 1.1.0; прямое изменение исходного MAT не поддерживается.

| Помощник | Назначение |
|---|---|
| `iml_get_current_frame` | Возвращает матрицу выбранного кадра. |
| `iml_get_selected_frames` | Возвращает набор выбранных кадров. |
| `iml_get_sequence` | Возвращает доступный контекст последовательности. |
| `iml_get_frequency_axis` | Возвращает вектор частотной координаты. |
| `iml_get_range_axis` | Возвращает вектор дальности/номинальной виртуальной высоты. |
| `iml_get_profile` | Возвращает метаданные профиля прибора. |
| `iml_get_metadata` | Возвращает метаданные запуска, кадра и проекта. |
| `iml_report_progress` | Публикует ограниченный ход выполнения/сообщение. |
| `iml_save_matrix` | Сохраняет производную матрицу. |
| `iml_save_plot` | Сохраняет рисунок. |
| `iml_save_table` | Сохраняет табличный артефакт. |
| `iml_register_feature` | Регистрирует интерпретируемый признак и метаданные. |
| `iml_register_candidate_result` | Регистрирует кандидатный результат, не решение эксперта. |
| `iml_add_warning` | Регистрирует предупреждение качества или интерпретации. |
| `iml_add_provenance` | Регистрирует происхождение метода, параметров и источника. |

## Правила применения
Read-помощники могут вернуть пустые данные, если контекст не передан. До расчёта проверяйте размер, единицы, статус профиля и пропуски. Save-помощники создают только производные выходы. При регистрации указывайте стабильные имена, единицы при наличии, значения и содержательные предупреждения. Оставляйте `confidence_score` null, если калиброванной уверенности нет; вероятность нельзя выдумывать.

## Минимальный пример
```matlab
frame = iml_get_current_frame();
f = iml_get_frequency_axis();
metric = mean(frame(:), 'omitnan');
iml_register_feature('mean_amplitude', metric, 'a.u.');
iml_add_provenance('algorithm', 'mean_amplitude_v1');
iml_save_plot('mean_over_frequency', plot(f, mean(frame, 1)));
```

Авторитетны точные сигнатуры помощников, поставляемые с приложением. Скрипт должен сообщать об ошибке, а не трактовать отсутствие данных как положительный научный результат.
