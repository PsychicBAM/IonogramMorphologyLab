# Parameter Estimation

Open **Ionogram Parameters** and choose **Load from last result**. For every estimate, inspect method name, units, input frame, instrument profile, calibration status, quality flags and uncertainty. Select **Accept**, **Reject** or **Indeterminate**, document the rationale, then select **Save expert edits**.

Parameter values are conditional estimates, not ground truth. A missing or provisional profile, uncertain trace, clipped frequency range, transformed display, interference or algorithmic abstention must remain visible in the report. Do not compare values across datasets without checking units, reference frames, profile compatibility and processing version.

When evaluating a method, retain held-out cases, compare against an independently reviewed reference, report errors and failures by subgroup, and state what cases were excluded. Synthetic labels are unsuitable as the sole external validation set.
