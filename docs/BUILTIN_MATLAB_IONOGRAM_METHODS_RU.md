# Встроенные методы MATLAB для ионограмм

## Назначение
`matlab_builtin/` содержит поставляемые эталонные методы MATLAB только для чтения. Они дают воспроизводимые инженерные процедуры и кандидатные детекторы; они не подтверждают ионосферную интерпретацию, точность или причинный механизм по изображению.

## Структура
- `core/`, `trace_detection/`, `rendering/` готовят производные входы и диагностические виды.
- `layer_detection/`, `es_analysis/`, `f_layer_analysis/` формируют доказательства кандидатов слоя.
- `spread_f_analysis/`, `interference/`, `branch_analysis/` описывают кандидатную морфологию и неоднозначность.
- `parameters/`, `comparison/`, `temporal_analysis/`, `reports/`, `tests/` поддерживают проверку и документированную разработку.
- `manifests/*.iml-matlab.yaml` задают точки входа, входы/выходы, параметры, статус и ограничения.

## Использование
Откройте MATLAB Studio, проверьте метод и манифест, выберите изолированную рабочую папку и запускайте на производных входах. Сохраняйте версию backend, профиль, параметры, хэш источника, пути выходов, предупреждения и журнал ошибок. Исходные MAT остаются только для чтения.

Слой, морфология и неоднозначность — независимые выходы. Например, `iml_detect_f2_candidate.m` даёт только свидетельство кандидата F2; `iml_detect_frequency_spread_candidate.m` описывает морфологию; `iml_detect_possible_ox_pattern.m` — неоднозначность. Не объединяйте их в один «тип ионограммы».

## Редактирование
Не изменяйте файлы в `matlab_builtin/`. Используйте действие MATLAB Studio для создания редактируемой копии в `matlab_user_methods/` проекта или пользователя с сохранением происхождения. Изменённая копия является локальным разработческим кодом и не наследует source-verified.

## Scientific Strict
Scientific Strict фильтрует правила и результаты по документированному статусу. Он не делает процедуру MATLAB научно валидированной. Методы без совместимых источника, профиля, области и ограничений остаются исключёнными или явно помеченными для разработки.

## Граница валидации
Синтетические примеры и встроенные тесты MATLAB проверяют интерфейсы и ожидаемый ход выполнения. Это не научные валидационные данные. Сравнение с документированным независимым эталоном необходимо до любых заявлений о качестве.
