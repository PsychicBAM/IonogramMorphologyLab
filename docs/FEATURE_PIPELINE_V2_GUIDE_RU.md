# Руководство Feature Pipeline V2 (RU)

**Версия:** `iml2-0.2.0`  
**Флаг:** `analysis.scientific_feature_pipeline_v2_enabled` (по умолчанию **false**)  
**Метка:** Экспериментальные признаки — не участвуют в текущей классификации

Не смешивайте результаты `iml2-0.1.0` и `iml2-0.2.0` без явного указания версии.
Доказательства 0.1.0 сохранены в `docs/_phase4b1_*`; текущие — в `docs/_phase4b3_iml2-0.2.0_*`.

## Разделение понятий

| Слой | Смысл в V2 |
| --- | --- |
| **Измерение** | Числа, маски, осевые линии, неопределённость |
| **Интерпретация** | Кандидатные геометрические чтения (ветви, *возможность* O/X) |
| **Классификация** | **Не выполняется** V2 в фазе 4B |
| **Валидация** | Синтетические геометрические тесты + автоматический теневой аудит реальных кадров; проверка владельцем ожидается. |

V2 **не** выдаёт `frequency_spread` / `range_spread` / `mixed_spread`.  
V2 **не** меняет пороги RuleEngine и морфологические решения.

## Первичный путь данных

Числовой кадр `extract_frame_consistent` → контракт сигнала → оси (если доступны) → SHA источника / профиль / версия.

PNG не является входом, если доступен числовой кадр.  
Нерешённые переменные (`Phs_all`, `Date_Time1`, `AmEsP`, `A_map_F`, `H_map_F`) не используются.

## Представления

1. Сырой кадр (научный)  
2. Диагностические производные  
3. Бинарные/вероятностные маски  

Нормализованный кадр никогда не сохраняется как «сырой».

## Экспертный интерфейс

Страница **«Диагностика признаков»**: слои, прозрачность, вписывание/100% без независимого растяжения осей, пояснения признаков, экспорт пакета.

## Далее

Фаза 4C определит, какие *проверенные* измерения смогут включать правила классификации.
