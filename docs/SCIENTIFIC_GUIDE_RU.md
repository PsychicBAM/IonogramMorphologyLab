# Научное руководство (RU) — Ionogram Morphology Lab 1.1.1

## Область и статус

IML фиксирует **кандидатные** морфологические и параметрические предложения по изображению. Это не доказательство физического механизма, не замена экспертного масштабирования и не операционная валидация метода. Синтетические данные проверяют ПО, а не научную валидность.

## Канонические токены морфологии

| Токен правила | Сериализация | Смысл в интерфейсе |
|---|---|---|
| `none` | `clean` | Явное рассеяние не обнаружено |
| `frequency` | `frequency_spread` | Кандидат частотного рассеяния |
| `range` | `range_spread` | Кандидат высотного рассеяния |
| `mixed` | `mixed_spread` | Смешанное — только при независимых признаках по обеим осям |
| `artifact` | `interference_dominated` | Доминирующая помеха |
| `not_assessable` | `not_assessable` | Оценка невозможна из‑за качества/ошибки |

Наличие трассы E/Es/F1/F2/F само по себе **не** означает рассеяние. Ошибка обработки никогда не становится положительной морфологией.

Актуальный аудит: [MORPHOLOGY_DECISION_AUDIT_V1_1_1.md](MORPHOLOGY_DECISION_AUDIT_V1_1_1.md).

## Модель доказательств

Оси результата должны оставаться раздельными: качество данных, морфология, неоднозначность, помехи, параметры, решение эксперта.
