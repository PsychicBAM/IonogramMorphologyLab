# «Лаборатория морфологии ионограмм» 1.1.0 — полное руководство

## Назначение
Ionogram Morphology Lab / «Лаборатория морфологии ионограмм» организует работу с ионограммами в MAT: импорт, аудит, кэш, визуализацию, интерпретируемые признаки, правила с источниками, сравнение с референсами, кандидатные результаты, решения эксперта и экспорт. Приложение само по себе не доказывает морфологию, механизм или точность.

## Первый запуск и язык
При первом запуске выберите язык интерфейса. Позже изменяйте его только через **Настройки → Общие → Язык интерфейса**. Верхних кнопок EN/RU намеренно нет. После смены языка при необходимости перезапустите или обновите вид.

## Рабочий процесс
1. Создайте проект в рабочем каталоге.
2. Импортируйте MAT/папку и проверьте переменные и профиль.
3. Выполните аудит качества; разберите нечитаемые файлы, неверную форму и нехватку метаданных.
4. Постройте производный кэш и откройте реальные кадры в Viewer.
5. Выберите кадры, запустите признаки/правила, проверьте разногласия и воздержания.
6. При необходимости отдельно зафиксируйте решение эксперта.
7. Экспортируйте CSV, JSON, HTML или Markdown с происхождением.

Импортированные MAT по умолчанию доступны только для чтения. Кэш и отчёты являются производными данными; SHA источника обеспечивает прослеживаемость.

## Режимы анализа
В **Настройки → Анализ → Режим** доступны:
- `fast_preview`: быстрый просмотр; не основание для итогового научного вывода.
- `standard`: сбалансированные параметры.
- `scientific_strict`: рекомендуемый режим по умолчанию; сохраняет качество, provenance, разногласия и воздержание.
- `custom`: явно выбранные пользователем параметры; фиксируйте отклонения в отчёте.

## Protected Scientific Study
Режим **Protected Scientific Study** необязателен и по умолчанию выключен. После намеренного включения и настройки он может применять защиту путей к указанным материалам исследования. Это не заменяет контроль доступа, этическое разрешение или план управления данными. Не включайте режим без проверки фрагментов путей и ожидаемой области действия.

## Результаты и ограничения
Результаты — кандидатные морфологии. `abstain`, `indeterminate` или null confidence информативны, а не являются сбоем. Null confidence означает отсутствие калиброванной вероятности. Нельзя выводить O/X-идентичность только из ветвления на изображении. Пользовательские профили и импортированные методы требуют собственной валидации.

## Расширения
MATLAB Studio предоставляет изолированные скрипты и плагины; Model Lab — модели разработки. Оба компонента должны сохранять provenance и не заменяют экспертную проверку.
