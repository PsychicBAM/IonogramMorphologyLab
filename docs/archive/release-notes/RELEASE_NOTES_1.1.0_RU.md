# Лаборатория морфологии ионограмм 1.1.0

**Дата выпуска:** 2026-08-01  
**English name:** Ionogram Morphology Lab

## Основные изменения

- Встроенная MATLAB-библиотека методов ионограмм (`matlab_builtin`, 82 файла `.m`) в MATLAB Studio
- Раздельные научные выходы: слой, морфология, неоднозначность, качество, параметры
- Редактор научных правил, лаборатория проверки правил, пакеты `.iml-rulepack` (9 встроенных)
- Страница параметров ионограммы с явными состояниями реализации
- Сравнение методов и конструктор конвейера
- Реестр источников подтипов Es (без «запомненного» активного списка букв)
- Справка расширена до 80 двуязычных разделов

## Поставка

Портативная сборка: `dist\IonogramMorphologyLab\IonogramMorphologyLab.exe`  
Установщик (при наличии Inno Setup): `installer\IonogramMorphologyLab_Setup_1.1.0.exe`

## Научные формулировки

Результаты остаются **кандидатной морфологией**. Методы не подтверждают физические механизмы только по изображению. Эвристики разработки и синтетические тесты не являются научной валидацией.
