# «Лаборатория морфологии ионограмм» 1.0.0

Первый базовый релиз продуктовой документации и валидаторов v1.0.

## Основное
- Двуязычный первый запуск и постоянный язык через **Настройки → Общие → Язык интерфейса**; верхних действий EN/RU нет.
- Проектная процедура: импорт MAT, аудит, производный read-only кэш, работа с кадрами, признаки/правила, решения эксперта и воспроизводимые отчёты.
- Режимы: `fast_preview`, `standard`, `scientific_strict` (рекомендуемый по умолчанию) и `custom`.
- Необязательный MATLAB Studio: библиотека скриптов, манифесты, реестр плагинов, изолированный runner и обработка MATLAB/Octave/отсутствующего backend.
- Model Lab для обучения в разработке/исследовании с model card, групповым split, воздержанием и явными development-метками.
- Необязательный Protected Scientific Study, выключенный по умолчанию.

## Совместимость и упаковка
Цель портативной поставки: `dist\IonogramMorphologyLab\IonogramMorphologyLab.exe`. Цель установщика при наличии Inno Setup: `installer\IonogramMorphologyLab_Setup_1.0.0.exe`.

## Научные замечания
Автоматические результаты остаются кандидатными. Модели разрешены только для разработки/исследований до внешней валидации. Исходные MAT остаются read-only по умолчанию. Отсутствующий backend или null confidence честно сообщаются и не превращаются в успех либо калиброванную уверенность.

## Известные ограничения
Для выполнения MATLAB требуется отдельный доступный backend. Валидность профиля прибора и метода определяется документированными доказательствами. Protected Study — настраиваемая защита, а не замена безопасного хранения и управления данными.
